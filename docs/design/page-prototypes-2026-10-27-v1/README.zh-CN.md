## 必须保留的边界

1. **美股核心热力图直接复用现有代码。** 保留现有布局算法、配色、内容、范围/权重切换、筛选和交互；原型只决定其外部容器的位置。
2. **现有 K 线直接复用。** 保留青蓝/品红等现有配色方案，以及平移、缩放、横纵轴操作、切换标的后的合理居中；不重写图表引擎，不用生成图片或新图表替代原组件。
3. **新闻保留等宽、不等高瀑布流。** 卡片实际宽度必须由同一个列宽规则计算，不能照搬图片中可能存在的列宽像素误差；不得把第一列做成加宽头条列，不得改成等高网格。
4. **宏观指标保留完整。** 指数、VIX、恐慌贪婪指数、黄金、油价、美元指数、美债和加密行情都保留。美债主卡显示 10 年期，点击展开 10/20/30 年期。
5. **分组及用户状态保留。** 不改变已有分组数据；迁移时保留排序、折叠状态、自选标的与用户偏好。
6. 上述保留模块之外，布局、容器、工具栏、按钮层级、导航和配色按新方案统一。

## 公共布局与自选

- 顶栏：品牌、全局搜索、北京时间/纽约时间、主题与设置。页面标题放在中央区域，避免多处重复品牌。
- 左侧：约 72px 的导航轨道，提供图标和简短中文标签；当前页用浅蓝底和蓝色文字标记。
- 中央：随窗口宽度伸缩。卡片内边距建议 16–24px，模块间距 16px。
- 右侧：独立自选面板，桌面建议 360–420px，可折叠或调整宽度；不再与左侧功能导航争用高度。
- 数据行：代码、主价格、主涨跌幅固定列对齐，数字使用等宽数字；公司名称作为次要信息。不重复展示同值的常规价与 EXT 价。
- 自选面板和中央内容独立滚动，分组标题与表头保持易于定位。展开/折叠、添加标的、更多操作的热区清晰。
- 图片中的“自动·当前常规”与演示时钟一致。真实系统在盘前、常规、盘后、隔夜等时段切换对应列名、主价格和涨跌基准；中国用户默认北京时间，同时保留纽约时钟。
- 自动模式必须由交易日历、交易状态、数据时间和数据覆盖共同决定，不把某个小时写死为常规或盘前。
- 首屏恢复用户模式与有效缓存时，保留行情所属时段和更新时间。当前时段数据未到时显示同结构占位或明确的旧数据状态，不能先把收盘价当成当前价，再突然跳成盘前价。
- 缺少当前时段报价时显示“— / 暂无报价”；不把其他时段旧价伪装成当前时段报价。
- 更新价格时不自动抢走焦点、不反复重建行、不跳动宽度；阅读、聚焦及菜单操作期间保持行顺序稳定。
- 同一公共自选组件跨路由复用，切换页面不丢失滚动位置与折叠状态。

### 个股行情

图表占据主要中央面积。按钮分两层：标的操作放在报价行；周期、指标、配色与图表设置放在下一行。页面容器尺寸变化时只调整图表容器尺寸，不能意外触发重置、自动放大或重新创建实例。

本图的价格轨迹是生成式视觉表达，不是原 K 线的逐像素快照。实施时以现有组件、真实数据和用户原先调好的交互为准。

### 加密货币

概览保留 BTC、ETH、六大资产市值合计和 BTC 市值占比。资产列表保留 BTC、ETH、BNB、SOL、XRP、ADA。选择资产后只更新选中态与详情区，不清空整页。

成交量和价格曲线沿用现有图表视觉；统一修改外围面板即可。窄窗口可将资产列表放在图表上方，而不压缩价格文字。

### 资金观察

概览采用“领涨板块、领跌板块、估算成交额合计、上涨/下跌数量”。原先带有主力增仓、资金流出推断的标题不继续沿用，除非确有相应数据定义与来源。

分布图横轴为涨跌幅、纵轴为估算成交额；旁边的行业排行用于定位与比较。排行选中和图上高亮可以联动，但悬停不应导致整体自动排序。ETF 净申赎保留为独立数据视图。

### 期权观察

将查询条件集中在顶部。OI 与估算 GEX 切换保留查询条件与选中标的，不重复查询未变化的条件。

最终图片把集中价放在指标卡和图下摘要区，不让多条文字标注遮挡柱形。若实施中保留现价参考线，其坐标必须由图表尺度转换计算；不能使用硬编码像素。GEX 单位、模型假设和数据时间继续依照真实代码与数据说明。

### 新闻资讯

三列在桌面上必须等宽，卡片由内容自然撑高；图文卡和纯文字卡可以混排。不要统一卡片高度、截断到同一底线或设置加宽首列。可以继续使用现有 CSS multi-column 与 break-inside 规则；实际采用何种实现以保持阅读顺序、键盘可达性和现有组件稳定为准。

卡片图片预留比例空间，避免加载后推动整个列表。新资讯出现时展示“有 N 条新资讯 · 点击更新”，用户点击再插入，不突然顶走正在阅读的内容。收藏按钮独立于整卡跳转，不抢滚动位置。图片中的新闻与事件时间均为示例，不可直接写入真实新闻源。

## 响应式与视觉规则

- 大屏：中央内容与右侧自选并排；自选推荐宽度独立于中央内容。
- 中屏：允许自选收起为抽屉，主图与筛选保持可操作；不要强行把所有列缩成小字。
- 小屏：新闻按 2 列/1 列自然降级；个股与加密图表优先获得足够宽度。此次交付只有桌面视觉稿，不声称已验证移动端。
- 建议设计令牌：画布 #F5F8FC、面板 #FFFFFF、主文字 #172B45、主要操作 #246BFD、边界 #E3E9F2。现有 K 线和热力图色值不被这些全局令牌覆盖。
- 涨跌必须同时有正负号/文字含义，不能只靠颜色。按钮具有悬停、焦点、按下、禁用和加载状态。
- 原型未展示的空态、失败、断线、无权限、无当前时段报价与陈旧数据状态，按详细指令书完成。
- 原型不规定从截图读取真实数值；文案、指标和行数据全部接真实业务状态。

## 开发验收重点

1. 八个原有主导航路由完整保留；本次新增原型覆盖其中五个页面。
2. 自选组件跨页面稳定复用；首次加载不出现“常规收盘 → 盘前”的错误价格含义切换。
3. K 线四向平移、轴拖动、缩放、标的切换居中、配色、成交量等行为与现有版本一致。
4. 核心热力图的内部外观与交互不被全局 CSS 意外覆盖。
5. 新闻三列实际测量等宽，卡片高度随内容变化；图片加载与新增资讯不打断阅读。
6. 宏观数据完整，10 年期美债主卡展开能看到 10/20/30 年期。
7. 图表 ResizeObserver、路由生命周期与销毁清理按详细指令书处理；避免重复实例与重建闪烁。
8. 真实浏览器验证再确认性能、响应式、键盘操作与数据状态；静态 PNG 不构成交互或行情正确性的验证证据。

## 生成与核对

使用内置 Image Gen 生成并逐张查看；最终选定五张 PNG，另附此前的总览参考。图像生成可能有细微文字、列宽或图表几何误差，因此工程实现必须遵守上述明确约束。

交付时核对图片可解码、尺寸、文件大小、SHA-256、预览入口的本地资源链接和压缩包文件列表。应用测试未因本轮设计资产任务而重跑；没有将静态设计当作已实现的功能。
