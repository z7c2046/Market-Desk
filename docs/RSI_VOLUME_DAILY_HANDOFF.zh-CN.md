**2. 当前运行的算法是什么。**

实际调用链为 `src/snapshot.js` → `src/indicators.js` → `src/signals.js`。页面入口为 `public/index.html` → `public/app.js` → `public/composables/useChart.js`。`inflection_site_assets` 不在当前页面入口的加载链上，不能只修改那个目录。

| 当前组成 | 实际计算与作用 | 代码位置 |
|---|---|---|
| 快慢线 | DEMA(14)、DEMA(30)，虽然前端仍使用 EMA / AUX 名称 | `src/snapshot.js:48` |
| 波动尺度 | 14 根真实波幅的滚动算术平均，用于归一化 | `src/indicators.js:38` |
| 超买超卖 | Williams %R(9)，≥ -15 阻止新向上切换，≤ -85 阻止新向下切换 | `src/signals.js:82` |
| 量能 | 当日量 / 含当日在内的近 20 根均量，调整评分大小 | `src/signals.js:89` |
| Mutant | 对数收益 × 260，经 EMA(5) 平滑，再用截至当时的滚动绝对值 P95 归一化 | `src/indicators.js:93` |
| RSI | 已有 Wilder RSI(14) 函数，但当前信号引擎未调用 | `src/indicators.js:192`、`src/signals.js:1` |

每根 K 线的原始分数为：

`0.45 × (快线－慢线)/ATR + 0.25 × (收盘－快线)/ATR + 0.15 × (快线－两根前快线)/ATR + 0.08 × (收盘－前收盘)/ATR + 自适应权重 × Mutant`。

再乘成交量系数：量比 ≥ 1.5 时为 1.15；1.0～1.5 为 1；0.7～1.0 为 0.85；更低为 0.70。Mutant 默认权重随最近五根同向程度在 0.108～0.252 间变化，源码注释上界 0.324 不符合默认公式。

进入阈值默认 ±0.22，随近期 ATR 分位最高放大到 1.6 倍。越过阈值先发 eB/eS，持续满足条件再发 B/S。中性阈值默认 0.08，但当前代码只清除待确认状态，没有真正把已经确立的 regime 切回中性。信号 reason 写成 `dema_cross_up/down`，实际并不要求本根发生双均线交叉。

因此它主要识别趋势和动量方向变化。它没有“比较两个价格高点/低点与 RSI”的逻辑，也没有“价格创新高但量能下降”或“放量但价格不再下跌”的结构判断。现有信号较晚出现有结构上的原因，单独缩短均线周期不能补齐这些能力。

**3. 两张截图应怎样转成规则。**

图二上半段展示了价格继续走高、阶段性量能变弱、RSI 上出现 Bear 标记；后半段展示了价格急跌后的低位、RSI 接近下边界和局部放量。截图支持把这些作为待研究形态，但无法精确读出各日 RSI、量比或 Bear 首次出现的日期，不能据图宣称某个参数一定捕捉到最高点或最低点。

| 用户观察 | 在新算法中的准确含义 | 必须补充的判断 |
|---|---|---|
| 价格新高、RSI 超买、量减少 | 顶部衰减观察；若 RSI 对应高点降低，才满足标准顶背离 | 两个比较锚点、RSI 差值、量能衰减幅度、价格转弱确认 |
| RSI 超卖、成交量放大 | 超卖放量观察 | 随后的价格是否守住低点、收盘是否回升、RSI 是否恢复 |

Bear 在这里表示看跌背离，不等于已经进入熊市；超买不等于已经见顶，超卖也不等于已经见底。标准 RSI 背离比较的是价格与 RSI 的两个高低点。[TradingView RSI 说明](https://www.tradingview.com/support/solutions/43000502338-relative-strength-index-rsi/)

成交量可以辅助判断趋势参与度；量价变化本身不足以确定反转。本文把“放量不跌”操作化为后续守住低点与价格恢复，并不据此断言存在某类主力资金。[Schwab 成交量说明](https://www.schwab.com/learn/story/trading-volume-as-market-indicator)

还需核实截图使用的具体 RSI divergence 脚本、参数和标记偏移。某些 pivot 指标在数根 K 线后确认，却把标记画回原高低点；截图上的标记位置不等于交易者当时已获得提示。[TradingView 关于历史回画的说明](https://www.tradingview.com/pine-script-docs/concepts/repainting/#plotting-in-the-past)

**5. 新模式的共同计算约定。**

策略名称：“RSI + 成交量拐点”；算法标识建议 `rsi_volume_v1`。以下所有“天数”均指交易日 K 线数量。索引 i 表示历史序列中第 i 根已完成日线。所有阈值集中在一个参数模块，响应与回测记录携带参数和版本。

| 项目 | V1 基线 |
|---|---|
| 周期 | 1d |
| RSI | 收盘价，14，Wilder 平滑；第一值由 14 个涨跌差的均值初始化 |
| RSI 边界 | 平均涨跌均为 0 → 50；仅平均跌为 0 → 100；仅平均涨为 0 → 0；预热不足 → null |
| 超买/超卖 | 70 / 30 |
| 新模式 ATR | 14，Wilder 平滑，先以完整 14 根 TR 均值初始化；命名与原版 SMA ATR 区分 |
| 相对成交量 RVOL20(i) | V(i) / mean(V(i-20)…V(i-1))，基准排除当日 |
| 高低点窗口 | 左 3 根、右 2 根；确认比极值晚 2 根 |
| 同类高低点间隔 | 5～60 根 |
| RSI 背离最小差 | 4 个 RSI 点，按绝对点数，不按百分比 |
| 价格新高/新低最小差 ε | max(前一锚点价格 × 0.003，第二锚点 ATR × 0.15) |
| 锚点量能 Q(p) | mean(V(p-2), V(p-1), V(p)) |
| 量能衰减 | Q(第二点) / Q(第一点) ≤ 0.85 |
| 显著放量 | RVOL20 ≥ 1.8 |
| 正式信号历史门槛 | 至少 100 根有效已完成日线；额外满足各窗口要求 |
| 主图默认显示 | 最近约 180 个交易日；行情计算默认请求 900 根，早期上市标的以实际可用为准 |

不使用今天之后的数据计算今天的分位数、阈值、均量或信号。这里的 Mutant 实现已经采用滚动 P95，不应误报它存在全样本 P95 前视问题。需要改进的是统一显示与引擎所用序列。

价格、RSI 和成交量必须取相同日期的锚点。V1 用价格 pivot 决定比较日期，在这些日期读取 RSI；不另外挑选更好看的 RSI 峰谷。该定义不保证与截图中的第三方脚本完全一致。

严格高点定义：H(p) 大于左侧 3 根及右侧 2 根的所有 high；严格低点对 low 作对称比较。相等高低点不算新 pivot。第二点 p2 确认日 d=p2+2。只配对距 p2 在 5～60 根内、最近的一个同类已确认 pivot p1；这个配对不满足条件就放弃，不能倒序搜索到任意有利点才算成功。

所有窗口只接受有效数据。缺失 OHLC、非有限数、负成交量及来源不明确的量须保留质量标记；不以 0 补齐未知数据。确知为零的成交量可以显示，但当前信号所需成交量窗口存在零值时，V1 暂不生成量价信号，以避免停牌伪背离。分母为 0、ATR 为 0、H=L 时相关规则不成立。

**6. 分支 A：顶部 RSI 背离 + 量能衰减。**

在 p2 确认当天 d，以下四项全部成立，生成“顶部背离预警”：

1. H(p2) ≥ H(p1) + ε，价格出现足够明显的新高。
2. RSI(p2) ≤ RSI(p1) - 4，动量高点降低。
3. max(RSI(p1), RSI(p2)) ≥ 70，至少一个锚点处于超买区。第二次 RSI 已降到 70 以下仍可成立。
4. Q(p2) / Q(p1) ≤ 0.85，第二次高点附近三日均量明显更低。

预警创建时冻结：比较日期、数值、ATR(p2)、顶部 H(p2)、失效价 H(p2)+0.5×ATR(p2)，以及确认价 `min(L(p2-2), L(p2-1), L(p2))`。

确认窗口为 d 至 d+7，含两端。任一已完成日线收盘价跌破冻结确认价，且该日 RSI 低于前一日 RSI，生成“顶部确认 / DV-S”。若 d 当天已经满足，可以当天确认；最早也只能是 d，不能画成 p2 当天已确认。

先判断失效，再判断确认：任一收盘价高于冻结失效价，预警失效；到 d+7 收盘仍未确认则过期。不要跟随新高持续抬高旧预警的失效价，也不要把以后数据补进原比较窗口。

如果只有 RSI 顶背离而成交量未衰减，可以在详情中列出“RSI 背离，量能条件未满足”，但不能发本分支正式预警或偷偷降低门槛。若只有超买和缩量、RSI 未形成下降高点，也不发 DV-S。

DV-S 是顶部风险确认。持有多仓时用于退出到现金；空仓时只显示提示。本期不把它转换成开空信号。

**7. 分支 B：底部 RSI 背离 + 下跌量能衰减。**

使用两个已确认价格低点 p1、p2。在 d=p2+2 同时满足：

1. L(p2) ≤ L(p1) - ε。
2. RSI(p2) ≥ RSI(p1) + 4。
3. min(RSI(p1), RSI(p2)) ≤ 30。
4. Q(p2) / Q(p1) ≤ 0.85。

生成“底部背离预警”。冻结确认价 `max(H(p2-2), H(p2-1), H(p2))`，失效价 L(p2)-0.5×ATR(p2)。

在 d～d+7 内，收盘高于确认价、RSI>30 且 RSI 比前一日上升，生成“底部确认 / DV-B”。任一日 low 低于冻结失效价则先失效；到期未确认则过期。若发现时 d 之前、p2 之后的任何 low 已低于该失效价，也不创建有效预警。

这一分支处理“价格新低，但动量与下跌参与度减弱”。它与下面的放量止跌分支并列，不要求同一次底部同时缩量与放量。

**8. 分支 C：超卖放量止跌，专门覆盖没有 Bull 标签的底部。**

此分支没有“必须形成两个低点”或“RSI 必须底背离”的条件。它按三个时间阶段工作，避免把放量大阴线立即当买入信号。

第一阶段：在已完成交易日 t0 发现超卖放量观察点，必须同时满足：

1. RSI(t0)≤30。
2. RVOL20(t0)≥1.8。
3. L(t0)≤前 20 根最低 low + 0.25×ATR(t0)，处于近期低位或创出新低。

当天只发“超卖放量观察”。冻结 L0=L(t0)、H0=H(t0)、A0=ATR(t0)、失效价 L0-0.35×A0。放量大阴线当日不能生成正式买入。

第二阶段：在 t0+2 或 t0+3 收盘检查是否开始止跌，四项全部成立才把该观察事件的“承接证据”设为已满足：

1. t0 后至当前的所有 low 都 ≥ L0-0.35×A0，至少观察了两根后续日线。
2. 当前 close > C(t0)。
3. 当前收盘位置 CLV=(close-low)/(high-low) ≥ 0.60。
4. 当前 RSI ≥ RSI(t0)+3。

最早满足日期记为 s，冻结不变。CLV 只是价格收回日内区间上部的事实，不命名成“主力净买入”。若到 t0+3 仍不满足，事件过期；若在任何一天跌破失效价，事件失效。

第三阶段：在 s 至 s+7 内，收盘高于 H0，RSI>30 且高于前一日，生成“放量止跌确认 / AV-B”。可以在 s 当天确认，因为已经有至少两根后续完整日线；不能回填到 t0。任何时刻先检查 low 是否跌破冻结失效价，失效优先。到 s+7 仍不确认则过期。

这一规则宁可等待价格恢复，也不会把所有超卖放量都标成买点。它可能错过部分 V 形急反弹，也可能晚于实际最低价；须通过回测衡量这个取舍，不能为了让 SNDK 截图好看就临时放宽阈值。

同一标的只允许一个活动的 C 类观察事件。期间新增放量日只加入证据，不重置计时与参考低点；结束后至少隔 3 根已完成日线才接受新的 C 类事件。A/B 每个锚点对只生成一个事件。

**9. 信号时间、状态与可解释性。**

共同状态为 candidate、confirmed、invalidated、expired。C 类第二阶段以证据字段记录，不另造可交易信号。每次状态变化追加事件，保留当时的事实；禁止刷新后把原预警改成“从一开始就已确认”。预警是已收盘数据得到的未确认形态，与盘中尚未收盘的预览是两个概念。

| 字段 | 必须表达的意思 |
|---|---|
| id / setupId | 稳定标识，含标的、策略版本、类型及锚点；不得每次刷新随机变化 |
| algorithm / algorithmVersion / parameters | 引擎身份和完整参数快照 |
| kind | 顶背离衰减、底背离衰减、超卖放量止跌 |
| direction / stage | bullish 或 bearish；候选/确认/失效/过期，不能靠 B/S 字符串猜测 |
| pivotTimes / anchorTimes | 形态引用的历史日期，仅用于解释 |
| detectedAt | 系统最早能够识别该形态的收盘时点 |
| confirmedAt / invalidatedAt / expiredAt | 相应状态真正发生的时点，尚未发生为 null |
| eventTime / time | 当前事件出现的交易日；提供旧图表适配时，time 必须等于事件日 |
| price | 事件日收盘价；pivotPrice 单独存，不能冒充当时成交价 |
| earliestFillDate | 正式确认后的下一交易日；无后续日线时不虚构成交 |
| triggerLevel / invalidationLevel | 创建时冻结的确认/失效阈值 |
| evidence | 价格高低点、RSI、量比、三日均量比、CLV、条件通过情况 |
| dataQuality / dataRevision | 数据是否满足条件，以及使用的固定行情版本 |

图上预警默认空心圆/浅色标记，确认使用实心箭头；失效与过期在详情保留，主图可默认隐藏。主图箭头必须在 detectedAt 或 confirmedAt 的真实事件日。背离连线可以连接历史锚点，但只能在当时已识别以后显示，提示框明确“结构日期”和“识别日期”。

同日两个底部分支同时确认，只生成一个有效买入动作，保留两项理由。正式顶部与底部同日冲突时，回测已有仓位优先卖出，空仓保持现金，记录冲突；候选顶部不阻止已经正式确认的底部信号。图上不能删除冲突事实来美化结果。持仓时重复买入不加仓，空仓时卖出不做空。

不要把 4 项条件满足 3 项或某个人工分数显示成“75% 成功率”。主区展示事实：例如“价格高点提高 2.4%，RSI 高点下降 6.1 点，三日均量下降 22%，尚未跌破确认价”。这些数字只可来自当前响应，不得写入示例常量。

**10. 日线数据与回测必须共用的底层规则。**

当前 TradingView 请求已经设置 regular session 和 splits adjustment；应保留，并显式返回交易所、币种、session、adjustment、交易日和收盘状态。核对成交量与价格的拆股口径；截图和本地比较时也要匹配是否分红复权。未引入分红现金流的回测只能称价格收益比较，不能称含分红总回报。

美股按 America/New_York 的交易日历判断收盘，包括夏令时、休市和提前收市。不能用中国日期跨零点判断美股日 K 是否完成，也不能只写死 UTC 收盘小时。非美股自选项保留，但使用各自市场日历；无法确定市场或最后一根完整性时，显示数据状态，保守排除不确定日 K 的正式计算。

历史 OHLCV 排序去重、验证 high/low 与 open/close 的关系。普通周末、节假日不补零成交量 K 线；缺失交易日及停牌须有明确状态。短于所需历史时显示“数据不足”，不显示“没有风险”。

图表、快照、雷达和回测使用相同 symbol、1d、复权方式、参数、预热和算法版本。显示窗口、BARS 控件和回测日期不能改变指标的计算起点。对于递推指标，固定数据版本与起点，或使用可恢复的指标状态；回测开始日前至少准备 260 根历史，历史较短时从实际首根开始并遵守 100 根门槛，明确实际覆盖范围。

对同一股票扫描时也应复用同一规范化行情，不能雷达取 600 根、图表取 900 根并从不同起点重算后默认为完全一致。公共源无法提供所需区间时如实返回 actualStartDate / actualEndDate 和质量信息。

缓存需要区分原始行情缓存与派生信号缓存。后者的键至少包含规范化标的、周期、数据版本、算法版本、参数、日线完成范围；增加策略切换后，不能仍只按 symbol/tf/limit 缓存旧信号。不同策略可以共享相同原始行情。

只读的逐日前缀验证要求：同一固定起点、同一数据版本、相同参数下，输入截至 t 的序列，与输入更长序列得到的截至 t 的事件必须一致。已结束事件可以追加后续状态，不能重写当时已知事实。数据供应商事后更正另记版本，不假装历史数据永不修订。

**12. 扫描与回测的具体产品规则。**

扫描必须可选择当前算法，默认最近 4 个已完成交易日。按 confirmedAt 或 detectedAt 计算年龄，不按 pivotTime。分开显示“底部确认”“顶部确认”“观察中”，不再靠 side 字符串长度推断确认状态。当前已失效或过期预警不计入活动观察列表，历史可查。同一股票可有不同日期的多个事实，摘要优先展示最近状态并明确是否冲突。

回测统一只做多/现金，初始为空仓。底部正式确认后的下一根有效交易日开盘买入；顶部正式确认后的下一根开盘卖出。候选事件不参与默认买卖。最后一根出现确认但没有下一根有效开盘时，保留待执行事件，成交数不增加。缺失 open 不得悄悄用当日 close 替代；返回无法模拟该笔成交的原因。

V1 采用“纯信号比较”作为默认回测：不设置隐含止损/止盈，直到正式退出或期末盯市。候选失效价是形态判断阈值，不是已经挂出的止损单；确认后的持仓不会因为旧候选失效自动在该价成交。界面须注明“未模拟保护性止损”。如果后续加入止损，应作为单独策略版本，并定义跳空、触发时点和成交模型，不混入本期基线。

| 默认比较行 | 买入 / 卖出 |
|---|---|
| RSI + 成交量确认 | DV-B 或 AV-B / DV-S |
| 原版 B/S 基准 | legacy_v1 的 B / S |
| 原版 eB/eS 基准 | legacy_v1 早期信号，单独列出，不与新模式候选混同 |
| 趋势修正版 B/S | legacy_v2 的 B / S，单独展示修复影响 |
| Buy & Hold | 研究区间第一根开盘买入，期末收盘盯市 |

每个策略行显示：净收益、收盘净值最大回撤、已完成交易数、已平仓胜率、平均已平仓收益、持仓时间占比、期末未实现盈亏。0 笔已完成交易的胜率应为“—”，不能是 0%。期末持仓只进入净值及 openPosition，不人为添加一笔获胜或亏损交易。价格收益与现金状态的基准统一，不默认增加杠杆。

初始研究成本建议每腿费率 5 bps、每腿滑点 5 bps，两者分开可调；这些只是模拟假设，不代表用户券商实际费用。买入成交价为下一开盘×(1+滑点)，卖出为下一开盘×(1-滑点)，手续费分别作用于两次成交金额；期末只盯市而不卖出时不扣虚构退出成本。额外比较 0、10、20 bps/腿的总成本敏感性。

开始/结束日期默认最近一年，允许拉长；信号用区间之前的数据预热，但从区间起始保持现金，除非另有明确策略设置，不按区间前历史信号补持仓。返回实际覆盖范围。显示“区间收益最高”可以，但不能把这个标签解释为未来推荐或稳定最优策略。

顶部效果不能仅靠新模式闭环净收益衡量，因为其买入机会也改变了。增加研究诊断：在相同原版 B 入场条件下比较原版 S 与 DV-S 退出；若使用“原版 S 或 DV-S 先到者退出”，明确这是新增退出层的独立实验。另记录信号后 5/10/20 个交易日收益及有利/不利波动，作为事后评估，不允许用于当时的过滤或参数选择。

**14. 必须通过的验收。**

| 场景 | 必须看到的结果 |
|---|---|
| Wilder RSI 基准 | 固定有效价格序列与独立参考计算一致；100 根门槛、null、横盘/单边边界各有明确断言 |
| RVOL | 当天成交量不能进入该天均量分母；未知量、零均量不能触发信号 |
| 顶背离正例 | 价格更高、RSI 下降至少 4、至少一锚点≥70、三日均量比≤0.85，才产生 A 预警 |
| 顶背离反例 | 只有 RSI>70，或价格和 RSI 同步新高，或量能条件失败，不生成 A 正式信号 |
| 底背离正反例 | 价格新低而 RSI 提高且量衰减可以；RSI 与价格共同新低不能靠背离分支买入 |
| 无 Bull 的底部 | 没有两个有效低点，但符合 C 的超卖放量、后续两日守住、恢复和突破时，仍生成 AV-B |
| 放量下跌未止跌 | 高 RVOL 与低 RSI 后继续跌破失效价，C 必须失效，不能产生买入 |
| 右侧确认 | p2 当天和 p2+1 不知最终 pivot；最早 p2+2 才能识别；交易再从真实确认的次日开始 |
| 前缀一致性 | 固定数据版本逐日截断与全量计算历史事件一致；后续上涨/下跌不改变以前的预警事实 |
| 失效/过期/重复 | 阈值冻结，失效优先；同一锚点对无重复；C 不因再次放量延长有效期 |
| 盘中数据 | 更改尚未收盘日线的价量不改变此前正式信号；只更新行情预览 |
| 交易日 | 周末、休市、夏令时、提前收盘正确；不按上海午夜确认美股日线 |
| 回测执行 | 下一有效日开盘；同日冲突规则正确；不做空、不重复加仓；无次日不开仓；未知 open 不替换 |
| 统计 | 手算小样本净值/费用/收盘回撤一致；未平仓不计已平仓胜率；0 交易显示“—” |
| 一致性 | 相同标的/版本/参数/数据的图表、扫描、回测确认日期完全相同 |
| 页面 | 首次进入、刷新、切标的、扫描打开、回测都为 1d；桌面/手机找不到分钟或小时控件 |
