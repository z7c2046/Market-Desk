Design Principles

三大设计特点

🌗双主题自适应

通过 prefers-color-scheme 媒体查询，将黑、白、灰系核心色绑定到 CSS 变量，自动跟随系统切换浅色 / 深色模式。

📈状态语义化

高饱和绿 #38ab70 表示数据上涨，亮红 #df4f46 警示数据下跌，让数字趋势一眼可辨。

🎆炫彩渐变点缀

橙、紫、粉三族渐变（--gradLinear ~ --gradlinear4）用于进度条等关键组件，营造现代化半拟物风格。

色板总览 · 7 大色系

② Theme Mapping

双主题变量映射

同一个变量在浅色 / 深色模式下指向不同色值。带蓝色描边的，就是当前页面正在使用的那一侧。

当前主题：浅色模式

③ Twin Colors

孪生色对比 · 差别到底在哪

系统里存在多组"几乎相同"的颜色。下方色带按 A / B 交替拼接——如果你能看出条纹，说明它们确实不同；看不出，说明差异小于肉眼分辨极限。

💡 规范建议：#2976ff / #2879ff、#cfcfcf / #cecece / #cdcdcd 这类孪生色，大概率是同一颜色在不同文件中手写产生的偏差。建议合并为统一的设计令牌（CSS 变量），避免维护成本。
